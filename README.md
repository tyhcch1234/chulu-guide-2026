## 互動功能

- **我的成績**：輸入五科等級，全站即時對應——合資格院校數目、最佳五科分數、所處路線層級、彈性收生是否適用（存於瀏覽器 localStorage）
- **課程資料庫**：777 個課程逐行收錄入學成績、學額、Band A 報讀人數、計分方法、科目比重與額外要求；可依院校／範疇篩選、按分數或競爭排序、關鍵字搜尋，點擊查看詳情
- **聯招計分器**：按各院校不同的等級換算表（5\*\* = 8.5 或 7）計算最佳五科
- **搜尋**：`Ctrl / ⌘ + K`，搜尋章節、院校、目的地、計劃
- **篩選**：留學目的地按授課語言／地區／學費篩選；培訓計劃即時搜尋
- **放榜物資清單**：勾選狀態自動保存

## 技術

純靜態：HTML + CSS + 原生 JavaScript，無建置步驟、無框架、無外部 JS 依賴（僅 Google Fonts）。
資料集中於 `assets/data.js`，可直接修改。

## 備註

非官方整理，僅供參考。所有數字、日期、費用、入學要求均照原書抄錄並標示頁碼；院校政策每年更新，報名前請以官方公布為準。
